PROJECT CONTEXT
==================================================

Nino XO is part of the NinoWorld universe.

NinoWorld is a character-based cactus adoption ecosystem where users adopt real cactus friends and interact with them through a mobile app and community.

Nino XO is a separate game app connected to the same NinoWorld account system.

This game is:
- subscriber-only
- no ads
- premium
- cute
- funny
- polished
- social
- fast and addictive in short sessions

The game should feel like part of the NinoWorld world, not a generic tic-tac-toe clone.

==================================================
CORE GAME IDEA
==================================================

Nino XO is a 1v1 XO / Tic-Tac-Toe game, but not with plain X and O.

Instead:
- each player chooses a NinoWorld cactus character
- that character becomes the token used on the board
- each move feels alive with cute placement animation and personality
- the board feels premium and playful
- the game is funny, social, and replayable

This should feel like:
“a NinoWorld character battle on a premium cute board”
not:
“a generic XO game with a skin”
