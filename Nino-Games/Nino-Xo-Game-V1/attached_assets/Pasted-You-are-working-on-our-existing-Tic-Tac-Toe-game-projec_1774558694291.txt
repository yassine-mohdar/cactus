3. Email OTP / Magic Link

- existing user login

B. Apple Sign-In
- Users can sign up or log in using Apple Sign-In

- If the email is new, create a new account automatically or guide them through a lightweight signup flow depending on the architecture

- A user must always be able to return to the same account
- Do not create duplicate accounts for the same user when account matching/linking is possible
- Preserve all user data when signing in through any supported method:

  - rankings
  - profile data

Recommended behavior:
- If a user previously registered with email and later uses Google or Apple with the same verified email, link the account safely if the current architecture allows it
- Avoid duplicate users caused by different auth providers
- Store auth provider information cleanly in the database
